### EARS Compliance Criteria (Q_H)

A TR passes if it satisfies >= 5 of these 6 criteria:

| # | Criterion | Catches |
|---|---|---|
| a | Contains `shall` | Missing requirement verb |
| b | Has trigger (`When/If`) or clear subject | Unstructured statements |
| c | Expected outputs >= 4 words | Under-specified outcomes |
| d | Preconditions list non-empty | Missing test setup |
| e | Stimuli list non-empty | Missing test inputs |
| f | Contains number+unit, HTTP code, REST verb, or endpoint | Vague non-measurable TRs |

Criterion (f) distinguishes specific TRs like `When GET /pet/{petId} is called, the system shall return HTTP 200` from vague TRs like `When systems communicate, the system shall facilitate seamless communication`.
